Programmer profesional jarang menyentuh mouse saat ngoding. Bukan karena gaya-gayaan, tapi karena tiap detik yang dihemat dari bolak-balik keyboard ke mouse menumpuk jadi jam dalam seminggu. Berikut tujuh shortcut VS Code yang paling berdampak, khusus untuk keyboard Windows/Linux (pengguna Mac tinggal ganti Ctrl dengan Cmd).

## 1. Command Palette: Ctrl+Shift+P

Ini pintu ke semua perintah VS Code. Mau install extension, ganti tema, format dokumen, semuanya bisa dari sini tanpa hafal shortcut lain. Ketik sebagian nama perintahnya, Enter, selesai. Kalau kamu cuma hafal satu shortcut, hafal yang ini.

## 2. Quick Open: Ctrl+P

Buka file apa pun dalam project dengan mengetik sebagian namanya. Jauh lebih cepat daripada mengklik folder di sidebar, apalagi kalau project-mu punya ratusan file. Bonus: ketik `@` setelah nama file untuk lompat ke fungsi tertentu di dalamnya.

## 3. Multi-cursor: Alt+Klik (atau Ctrl+D)

Punya 10 baris yang perlu diubah dengan pola sama? Jangan edit satu per satu. Tahan Alt lalu klik di beberapa tempat untuk menaruh banyak kursor sekaligus, lalu ketik sekali dan semua berubah bersamaan. Alternatifnya, blok satu kata lalu tekan Ctrl+D berulang untuk memilih kemunculan berikutnya satu per satu.

## 4. Pindah baris: Alt+Panah Atas/Bawah

Baris kode perlu ditukar posisinya? Taruh kursor di barisnya, tekan Alt+Panah Atas atau Bawah. Tidak perlu cut-paste lagi. Kecil, tapi dipakai puluhan kali sehari.

## 5. Duplikat baris: Shift+Alt+Panah Bawah

Mirip di atas, tapi untuk menggandakan baris. Sangat berguna saat bikin daftar yang polanya mirip, misalnya beberapa baris konfigurasi atau item array.

## 6. Komentar cepat: Ctrl+/

Blok kode lalu tekan Ctrl+/ untuk mengubahnya jadi komentar (atau sebaliknya). Berlaku untuk bahasa apa pun karena VS Code tahu sintaks komentar tiap bahasa. Debugging jadi jauh lebih santai.

## 7. Terminal terpadu: Ctrl+`

Buka/tutup terminal tanpa meninggalkan editor. Kamu bisa menjalankan `npm start` atau `git status` lalu kembali ngoding dengan sekali tekan. Tidak perlu Alt+Tab ke jendela terminal terpisah.

## Buat shortcut versimu sendiri

Tujuh shortcut di atas adalah bawaan, tapi VS Code mengizinkanmu membuat atau mengubah shortcut apa pun. Buka Command Palette (Ctrl+Shift+P), ketik "Preferences: Open Keyboard Shortcuts", dan kamu akan melihat daftar semua perintah beserta shortcut-nya.

Klik ikon pensil di perintah mana pun untuk mengganti tombolnya. Misalnya kalau kamu lebih nyaman dengan gaya Vim atau Sublime Text, kamu bisa meniru skema mereka sebagian tanpa install apa pun.

Satu kebiasaan yang layak dibangun: setiap kali kamu melakukan sesuatu dengan mouse tiga kali dalam sehari, cari perintahnya di Command Palette dan hafalkan shortcut-nya. Dalam beberapa minggu, mouse-mu akan jauh lebih jarang tersentuh saat ngoding.

## Cara menghafalnya

Jangan coba hafal semuanya sekaligus. Pilih satu yang paling sering kamu butuhkan minggu ini, pakai sampai jadi refleks, baru tambah yang berikutnya. Tempel catatan kecil di monitor kalau perlu. Dalam sebulan, ketujuh shortcut ini akan terasa seperti perpanjangan tanganmu, dan kamu akan heran kenapa dulu betah pakai mouse untuk semuanya.
