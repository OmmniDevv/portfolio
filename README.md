## Overview

A Genshin Impact-themed developer portfolio built with **Next.js 14 App Router**, featuring immersive anime aesthetics, interactive elemental animations, and a fully responsive design. Every detail is handcrafted — from the SVG rune splash screen to the Konami code easter egg.

---

## Features

```
VISUAL & ANIMATION
├── Fullscreen splash screen with SVG rune draw animation
├── Canvas particle system with mouse repulsion in the hero
├── Matrix-style gold katakana code rain background
├── Custom animated cursor with wisp orb and particle trail
├── Scroll-triggered staggered section reveals
└── Vertical elemental energy bar scroll progress indicator

INTERACTIVE
├── Genshin element cards — hover to swap icons, click to flip
├── Elemental burst animation on card click
├── GitHub repository artifact cards with shimmer scan line
├── Hold-to-confirm contact form submit button
├── Konami code easter egg — 5-star wish animation + waifu card
└── Typewriter hero subtitle with replay on click

SECTIONS
├── Hero          — Vision frame with rotating rings
├── About         — Parallax tilt card + auto-type terminal
├── Party Members — Genshin character cards with modal
├── Waifu         — Nadeshiko Kagamihara shrine section
├── Skills        — Elemental icon cards with proficiency flip
├── Projects      — GitHub API artifact cards with filter
├── Services      — Commission board with animated sigils
├── Contact       — Traveler-themed form with social links
└── Footer        — Ornamental SVG divider + quote
```

## Getting Started

```bash
# Clone the repository
git clone https://github.com/OmmniDevv/omnidev-portfolio.git
cd omnidev-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

```bash
# Production build
npm run build
npm start
```
